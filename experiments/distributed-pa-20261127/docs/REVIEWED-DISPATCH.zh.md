# 领取之后，发送之前

| 阶段 | 核对 | 写入 |
|---|---|---|
| 主 Agent 比较席位 | 地区、能力、占用、预算 | 无 |
| 对选中席位复核，领取 | 当前授权、席位、预算版本、原任务和原文摘要 | 租约；不能发 |
| 对同一租约再次复核，开始 | 同一主持者、席位、提供方、通道、处理地区、预算和输入；当前版本、租期与围栏 | 开始事件和 outbox 一起提交 |

预算或授权变了，即使看板修订号没动，原选择也会被拒。已经领取但未发送的任务保留租约，期满后才能重新核选；另一席位可处理独立任务。提交失败会同时回滚开始事件和 outbox。重复提交已成功持久化的同一开始事件不返回第二张发放许可。

`storage/sql-journal.mjs` 的 `reviewedDispatch` 默认不配置。实验配置下，`inspectChoice` 返回对主持者、作用域、任务、此前围栏、席位路由和审查事实做绑定的比较值；持有它不赋权。`claimChoice` 与 `beginChoice` 各自在同一权威事务读取宿主提供的当前事实，而不是信任客户端、缓存或原先的读回。传入请求只是供宿主验证身份的上下文；宿主须把选择范围、发放权限和专用测试账号绑定到解析器，保证权限或预算变更更新相应代次，且解析和变更在同一事务域。选中标记仅供宿主流程，公开看板仍只有既有别名和汇总状态。存储只保存别名、主持者别名、代次和摘要，不保存原文、密钥或账号凭证。

## 实际发送之前：独立的本地模拟关卡

这组试验保护经该入口领取的租约。旧的内部 API 和此前实验仍可读取和重放；正式采用时应只开放已复核的入口，另审计能写原始账本的宿主权限。已核预算指宿主给出的当前审查结论，不扣费，不分配跨任务余额。可选的 `reviewedDispatch.mockEgress` 默认未配置。开启后，账本提交 begin 的同一事务只给原尝试登记一条待处理记录，不输出可用的发送许可。真正模拟派送的事务重新核主 Agent、任务、原输入摘要、授权代次、预算代次、处理地区、席位路由、原围栏和租期。宿主提供同事务的策略解析器和当前时钟；授权和预算代次不得回用。模拟结果与原尝试绑定，只可能有一条本地模拟回执，或记录为未知。冷启动可读原回执，重复调用也只回读；未知结果不会重发。读历史仍要有原审查人身份和任务阅读权，不会恢复派送权限。撤权发生在模拟接收之后，则保留既有回执。模拟回执不写入真实任务账本的验收，不解锁合稿。

模拟表与策略能在同一个 SQLite 事务内完成检查和写入；远端 PA 不在这个事务里。此实现没有发送函数、网络或真实 PA SDK。真正的跨服务发送仍需专门审计供应商的幂等键、原请求回查、可能已收到的错误、与撤权发生的先后。无法证明未发送时停在原尝试，不用新 ID 试探。旧宿主对于原账本的直接访问仍是受信任边界，公开调用者不得获得原账本写接口。生产和真实账号未启用。

验证：`node --test tests/reviewed-dispatch.test.mjs`。使用两个实际连接同一临时 SQLite，测试授权变化、换路、预算变化、错误原文、过期重选、故障回滚、重复 begin 和独立并发。

另运行 `node --test tests/reviewed-mock-egress.test.mjs`，覆盖 begin 之后再撤权、回滚、连接重开、其他任务独立、供应方状态未知与旧实验不回补模拟派送。看板追加四步「按下派送后，授权撤回了」；四帧只保留示例别名、状态与原任务和独立项的先后，没有模拟回执内容或摘要。

## 确认未发出，才创建新尝试

| 原尝试的本地结果 | 主 Agent 能做什么 |
|---|---|
| 已登记，尚无模拟接收 | 有该任务阅读权和显式关闭权限的原主 Agent 可关闭旧编号。销记和释放旧租约在同一 SQL 事务；任何一项失败就全部回滚。 |
| 收到回执 | 核回原回执。不重新派发。 |
| 结果未知 | 等可核对的原记录。不重发，不按「未发送」处理。 |

关闭后仍需按现行授权、预算、处理地区与席位重新核选。旧处理员再来只读到「已关闭 · 未发送」，旧编号永远不能再消耗；新尝试另有编号。关闭操作使用独立的宿主权限 `canCloseMock`，不靠当前派送预算放行；台账的普通回执或对账入口不能给已登记的模拟尝试制造已接收或未发送证明。此处能确认未发送是因为模拟收件与关单共享同一个 SQLite 事务，真实服务需要其自己的可信回执与撤权机制。
