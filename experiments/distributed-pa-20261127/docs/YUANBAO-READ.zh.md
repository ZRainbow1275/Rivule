# 元宝只读看板候选

同一版账本，同一套读规则。元宝、个人 Muse 的状态读入口与主看板对同一授权范围调用同一投影，三方都将「已收到」「已交稿」「已验收」分别显示。MCP 给受限查询，Skill 定义什么时候查、允许说什么。主 Agent 才能验收，依赖只看前置验收状态。

`yuanbao/read-board.mjs` 仅提供两个工具，解析调用身份、代号映射和授权全部由服务端决定；读完再复核一次身份与可见范围，避免撤权发生在读中途。返回只含安全代号、状态/证据类型、任务修订、更新时间和授权范围内的依赖。未交付 OAuth 服务、真正聊天卡片或上线包。示例只允许一个隔离且全部为合成数据的看板；多租户拿真实数据前需要单租户版本、审计和区域审查。

`yuanbao/SKILL.md` 是指令样稿。使用合格企业单独绑定真实 OAuth MCP 地址、只勾选两个工具以后，再在腾讯元宝按官方格式跑对话评测。不要把令牌放进 Skill，也不要让元宝对 Rivule 排他席位执行重发。20 个应用场景 + 2 个服务端额外授权用例，本地通过。多轮及触发用例由脚本模拟，产品真实自然语言理解、模型、登录和企业审核均未试。
