# 飞书 Aily 企业应用：会话 → 文字 → 运行 → 验收

| 阶段 | 保存证据 | 丢回执时 |
| --- | --- | --- |
| 创建专属会话 | 同一用户 Aily ID 和实际会话 ID | 不重复建会话；转对账。 |
| 发纯文本 | 同一会话、同一消息键、同一内容摘要和同一发送者 | 官方同会话消息去重 72 小时；模拟仅允许显式启用的一次同键重放。 |
| 创建 Run | 同一应用、会话和精确 Run ID，独立于消息回执 | 不重发。读原会话；仅在完整单页有唯一同应用候选，且 GET 或列表带回原 metadata 时确认。 |
| 结果 | 原 Run 完成后，读取同一 Run 的唯一最终回复，保留纯文本 | 多页、旧回复、附件或需要给助手补充信息时暂停。主 Agent 验收是另一步。 |

依据[飞书 Aily 多轮对话官方文档](https://aily.feishu.cn/hc/8qluoxsa_zi14u22m)。这是纯离线合同。没有读取或启动个人豆包工作伙伴，更没有扩展到群聊、通讯录、知识空间或外部技能。真实接入需独立的有权限企业用户，专用发布应用和专属会话，只允许公开文字；预算和处理/留存区域需核验。宿主必须为每次写先做可恢复原子保存，校验作用域后再执行。现在没有宿主授权、真实凭据、应用调用或计费。Run 返回 200 或 COMPLETED 都不会直接解锁合稿。
