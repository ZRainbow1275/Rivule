# 飞书 Aily 企业应用：会话 → 文字 → 运行 → 验收

| 阶段 | 保存证据 | 丢回执时 |
| --- | --- | --- |
| 创建专属会话 | 同一用户 Aily ID 和实际会话 ID | 不重复建会话；转对账。 |
| 发纯文本 | 同一会话、同一消息键、同一内容摘要和同一发送者 | 官方同会话消息去重 72 小时；模拟仅允许显式启用的一次同键重放。 |
| 创建 Run | 同一应用、会话和精确 Run ID，独立于消息回执 | 不重发。读原会话；仅在完整单页有唯一同应用候选，且 GET 或列表带回原 metadata 时确认。 |
| 结果 | 原 Run 完成后，读取同一 Run 的唯一最终回复，保留纯文本 | 多页、旧回复、附件或需要给助手补充信息时暂停。主 Agent 验收是另一步。 |

依据[飞书 Aily 多轮对话官方文档](https://aily.feishu.cn/hc/8qluoxsa_zi14u22m)。这是纯离线合同。没有读取或启动个人豆包工作伙伴，更没有扩展到群聊、通讯录、知识空间或外部技能。真实接入需独立的有权限企业用户，专用发布应用和专属会话，只允许公开文字；预算和处理/留存区域需核验。宿主必须为每次写先做可恢复原子保存，校验作用域后再执行。现在没有宿主授权、真实凭据、应用调用或计费。Run 返回 200 或 COMPLETED 都不会直接解锁合稿。

## 多进程原子派工演练

`storage/aily-stage-journal.mjs` 把上面的纯状态机接到隔离 SQLite。每次准备按任务所属租户、用户、工作通道、专用应用和任务号查询，初次写入锁定正文摘要。第 N 版的会话、消息或运行写入，只有一个进程能把状态升为第 N+1 版。更新和阶段日志同一事务提交，且只向这次胜出的测试调用返回一次模拟请求。旧票据、重复读取、第二次成功尝试和回滚后的事务均不能再返回新的写请求。数据库不留正文、回执正文、凭据、推理或联网能力；其模拟票据只是同轮关联标识，不作为真实鉴权。

模拟进程突然中止后，冷启动只读当前状态。标记原请求结果不明是单独动作，不能由进程退出推断未发送。会话无确证停在人工检查；消息只在原方案选中一次、同正文、同会话、72 小时内可模拟同幂等键的重试；运行回执丢失只读原标识。迟到的旧应答不会覆盖当前版本。模拟拿到明确同次运行的结果正文，只交回主 Agent 待审核，不自动在任务看板宣告完成。

验收包括两个独立节点进程同时争抢同一个 SQLite 阶段、事务写审计失败、冷启继续核对、不重复扣动作、绑定改变和晚应答。本地 Node 测试仍无外网请求。真实接入前另行确认账号授权、储存区域、额度、工具关闭、可信宿主和同步事务；不得把这份测试状态装配成默认连接。
