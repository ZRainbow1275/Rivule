## Cue 投递状态独立显示

| 提供方回应 | 看板记录 | 下一步 |
|---|---|---|
| 已投递 | 执行中 | 读取同一专用线程上的对应运行与产物，另做主 Agent 验收。 |
| 待所有者审核 | 待审批 | 私有账本保留原请求号。只查同一尝试、同一原文的回执，不补发。 |
| 限流 429 | 限流 | 保留原席位，等待并核实。不切号、不自动重投。 |
| 明确拒绝 | 已拒绝 | 复核当前配置或权限，按已证明关闭的状态决定后续。 |
| 超时、未知或回显损坏 | 投递待核 | 只对账；查不到原消息不表示一定没发送。 |
| 查到原输入 | 已见原输入、仍待核 | 这是投递证据，不是交稿、结束或验收。 |

只用该凭据自己的专用 Cue 线程；不能对共享给自己的其他所有者线程清空连接器。只读核对发现的消息 ID 与提供方请求号分开保存。看板不显示原请求号、原文、令牌或其他账号数据。实验未实接。DuMate 断流延用历史补读的已测策略，不同供应商的回执不要复用。
