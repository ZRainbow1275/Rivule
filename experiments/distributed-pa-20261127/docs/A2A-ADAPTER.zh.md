# A2A 派工协议试验：先固定同一次投递

A2A 1.0.1 是协作协议，不是某个手机 PA 的隐藏派单入口。接线必须由服务端配置评审过的专用绑定、账户与处理地域。此处只有 Mock 传输，未发现或登录实际端点。

账本先在事务内写入同一次派工；只有新提交者能出站。messageId 由已提交尝试确定，发送方不能切换账户或选临时网址。供应商协议可按消息号去重，但未保证；如果服务创建了任务后丢回包，两次补跑仍没有第二次出站。只能查证原请求。无任务号或会话号时，列表没有结果不等于没有执行。回包仅在含对应的用户消息证据时进入「已收到」，即使供方写「完成」也不能替代待验收结果。回包没有可关联证据时保守待核，未实现真实查询或传输服务器。

范围：公开短文本、测试 SQLite 事务、固定席位、无外出、无凭据、无附件。协议与产品能力需分别核验。[A2A 传输示例及语义](https://a2a-protocol.org/v1.0.1/specification/#331-idempotency)
