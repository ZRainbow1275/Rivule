# QQ 提示与下一步

打开 QQ 主面板查看连接、绑定和本轮通知状态。点击“刷新”会原地更新当前面板；使用“返回总览”入口回到任务总览。刷新不会代替所有者的验证与开启操作。

| 设置页提示 | 下一步 |
| --- | --- |
| 持续通知待开启 | 所有者检查部署配置，再刷新 |
| 确认接收 QQ 账户 | 回到设置，确认当前接收账户绑定 |
| 等待 QQ 连接就绪 | 检查连接阶段与运行预算模式 |
| 权限更新待确认 | 曾收到关闭或移除记录；核对 QQ 资料卡的接收设置，再刷新 |
| 已达到你设置的暂停时长 | 在「运行预算」增加时长或改为仅提醒，再启动连接 |
| 已达到提醒时长，连接可以继续 | 仅提醒模式不会自动暂停；按需要调整阈值 |
| 今日通知额度已用完 | 等待 UTC 配额重置；当前上限每日 100 次 |
| 准备开启本轮通知 | 点击“验证并开启本轮通知”，本次验证成功后开始接收新动态 |
| 验证已通过，等待队列就绪 | 刷新查看，或取消本次开启 |
| 本轮通知已开启 | 获准项目可按当前来源与会话证明发送；需要时暂停 |
| 持续通知已暂停 | 检查当前绑定、权限与来源，再开启新一轮 |
| 最近发送正在确认 | 等待后刷新，避免重复发送 |
| 上次发送结果待确认 | 亲自检查 QQ，再确认已检查结果 |
| 连接预算需要检查 | 所有者检查预算配置 |

连接时长默认仅提醒，120 分钟是可调整的初始每日阈值；可主动选择到点暂停。保存预算不清零计时，会暂停原通知授权，需要重新开启。最小主动发送间隔为 3 秒。设置页中的频道状态不代表每个来源都已接通；某个来源或事件失败时，查询其原回执。绑定与权限变化后，重新确认当前目标。
