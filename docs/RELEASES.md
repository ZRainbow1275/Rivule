# Rivule 版本

## v0.4.2 · 2026-10-21

这是公开源码补丁；生产部署尚未完成，QQ 与 Discord 双渠道实收验收仍待完成。源码同步不等同线上服务已升级。公开源码的 MCP server 元数据版本仍保留 0.4.0，本补丁未修改 owner 模块。

- 修复 QQ 通知状态冷启动恢复时缺失空表的问题：仅为 v2 状态补回缺失的 attempts、events、approvals、quotas 与 enrollments 空表。
- 保留已有非空记录、配额、去重信息和结果不确定的发送记录。拒绝已有表类型损坏、非法拆分路径及新旧存储格式混用，不清空或猜测修复数据。
- 不改变消息协议、接收账户、来源/项目允许名单、会话授权、撤销、暂停、预算或频率限制；不自动激活、续权或重放旧消息。

自托管更新后仍须分别核对通知回执和接收端实收，不能仅凭启动正常或设置验证成功认定任务通知已送达。

## v0.4.1 · 2026-10-21

v0.4.1 是源码补丁版号；公开源码的 MCP server 元数据版本仍保留 0.4.0，本补丁未修改该字段。

- 为 QQ 任务通知的发送前检查保留有界诊断，区分检查阶段与可确认的原因；未知错误只显示通用提示，不公开原始错误内容。
- 持续通知面板同时核对任务队列。队列暂停或状态无法确认时，不再仅凭网关授权显示「本轮通知已开启」。
- 保留未发送与发送结果未知的区别；刷新只核对状态，不重新授权、不补发历史消息。
- 不改变项目/来源允许名单、接收账户、配额、发送间隔或会话授权边界。所有者重新开启后，仍须以新通知的原回执和接收端实收完成独立验收。

此版本修复诊断与状态展示，不表示所有安装的普通项目通知已完成实收验收。

## v0.4.0 · 2026-10-20

- QQ 设置新增「运行预算」：默认仅提醒，初始每日阈值为 120 分钟；达到阈值不会强制中断连接。
- 所有者可调整阈值，或主动选择到点暂停。保存设置保留今日计时，暂停旧通知授权，需要本人重新开启。
- 本轮通知授权限当前连接会话，不再以固定两小时作为默认终止时间；不跨会话自动续权，不放宽绑定、来源、项目、权限、频率与配额限制。
- 验证消息成功与真实任务通知实收分开确认；项目允许名单为空时，普通项目通知仍会被拒绝。

版本号标识公开源码，不是云服务部署标识。公开配置保持安全默认值，不包含任何实际安装的账户、接收方、权限记录或部署配置。自托管安装需独立完成配置和实收确认。

连接计时不代表 Cloudflare 账单额度，实际用量请在 Cloudflare 控制台查看。本版本不修改套餐、消费上限或平台配额。
