# 障碍说明与任务终态

本页记录候选通知的呈现规则。PA 可以在最后一次更新里同时给出任务结果和遇到的障碍。例如，“样张已经交付；原定纸张未能按时到货”。任务状态决定是否还要关注，障碍原文保留在更新里。

| PA 上报 | 通知的主状态 | 障碍写在哪里 | 计入「需关注」 |
|---|---|---|---|
| 进行中，且报告了障碍 | 受阻 | 当前阻塞 | 是 |
| 已完成，附有障碍说明 | 已完成 | 来源备注 | 否 |
| 已取消，附有障碍说明 | 已取消 | 来源备注 | 否 |
| 失败，附有障碍说明 | 失败 | 来源备注 | 是 |

Discord 总览图优先显示来源的结果摘要。选中分支后，可在「来源备注」查看原文。QQ 在任务摘要后另列备注。摘要为空时，图卡显示来源备注；不会自行编写结果或将障碍说成已解决。处于待确认、快照过期或状态冲突的记录保留各自的提示。
